# 키즈텐 · 우리 아이 예상 키

제공된 기존 홈페이지 화면을 바탕으로 만든 반응형 개편 시안입니다. 기존 PHP 사이트에 배포되거나 연결된 상태는 아닙니다.

## 실행

별도 패키지 설치나 빌드 없이 `index.html`을 브라우저에서 열 수 있습니다. 로컬 서버는 저장소 루트에서 다음과 같이 실행합니다.

```sh
npm start
# 또는 python3 -m http.server 3000 --bind 0.0.0.0
```

Node.js가 있는 경우 계산 테스트를 실행할 수 있습니다.

```sh
npm test
```

## 구성

- `index.html`: 한국어 화면, SVG 일러스트, 계산 근거와 성장 가이드
- `styles.css`: 보라색 브랜드, 데스크톱/모바일 반응형 스타일
- `calculator.js`: 부모 키 검증과 중간부모키 계산
- `app.js`: 입력 오류, 성별 선택, 예시, 결과 복사, 초기화
- `tests/calculator.test.cjs`: 계산 및 입력 경계 검증

입력은 메모리에서만 처리하며 서버 전송, 쿠키, 로컬 저장소를 사용하지 않습니다. Noto Sans KR 웹폰트만 Google Fonts에서 가져오며, 접속되지 않으면 시스템 글꼴을 사용합니다.

## 계산 정책

남아는 `(아빠 키 + 엄마 키 + 13) / 2`, 여아는 `(아빠 키 + 엄마 키 - 13) / 2`입니다. 화면은 소수점 첫째 자리로 표시하며 참고 범위는 ±10 cm입니다. 부모 키 입력 범위는 이 시안의 입력 검증 기준인 100~230 cm이며 소수점 첫째 자리까지 받습니다.

현재 키, 나이, 성장 속도, 골연령을 반영하지 않는 참고값입니다. 개인의 최종 키, 확률, 치료 효과를 예측하거나 보장하지 않습니다. 근거: [AAFP, Evaluation of Short and Tall Stature in Children (2015)](https://www.aafp.org/pubs/afp/issues/2015/0701/p43.html).

## 기존 홈페이지 적용

현재 저장소에는 기존 PHP 소스나 운영 배포 설정이 없습니다. 가장 간단한 연결 방법은 이 디렉터리를 별도 경로에 배포한 후 기존 예상 키 탭에서 해당 경로로 이동시키는 것입니다. 기존 PHP 레이아웃 안에 직접 넣으려면 `main` 영역을 이식하고 CSS 선택자를 컴포넌트 범위로 한정해 기존 사이트 스타일과 충돌하지 않도록 통합해야 합니다. 적용 전 실제 운영 계산 정책과 브랜드 자산을 확인하세요.
